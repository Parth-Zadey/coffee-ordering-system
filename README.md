# ☕ Brew & Bean — Coffee Ordering System

A modern and responsive **coffee ordering web application** built using **HTML, CSS, and JavaScript**.

The project started as a Python/Tkinter desktop coffee-ordering application and was redesigned as a browser-based web application for easier access and portfolio presentation.

## 🌐 Live Demo

**[View Live Website](#)**


## 📸 Features

* ☕ Browse a selection of coffee drinks
* ➕ Add items to the cart
* 🔢 Increase or decrease item quantities
* 🗑️ Remove individual items
* 🧹 Clear the complete order
* 💰 Automatic total price calculation
* 🛒 Interactive shopping cart
* ✅ Checkout confirmation
* 📱 Responsive design for desktop, tablet, and mobile
* ✨ Smooth animations and interactive UI

## 🧑‍💻 Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, responsive layout and animations
* **JavaScript** — Cart functionality and application logic

## 📂 Project Structure

```text
coffee-ordering-system/
│
├── index.html
├── style.css
└── script.js
```

### `index.html`

Contains the structure of the coffee shop website, including the navigation, hero section, menu, cart, about section and checkout modal.

### `style.css`

Contains the complete visual design, including:

* Dark coffee-themed interface
* Responsive layouts
* Coffee cards
* Cart styling
* Animations
* Hover effects
* Mobile responsiveness

### `script.js`

Handles the application's functionality:

* Menu rendering
* Adding products to cart
* Quantity management
* Removing products
* Clearing the cart
* Price calculation
* Checkout
* Order confirmation

## 🎯 Project Goal

The goal of this project was to transform a desktop coffee-ordering concept into a modern web application while practicing frontend development and JavaScript-based application logic.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/coffee-ordering-system.git
```

Open the project folder:

```bash
cd coffee-ordering-system
```

Then open `index.html` in your browser.

No backend or installation is required.
